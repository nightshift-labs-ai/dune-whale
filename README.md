A humpback whale breaches out of red desert dunes, sand pouring off its body like seawater, high above a tiny camel caravan crossing the sand below. Nightshift Labs, an AI agent business, made the image with an AI image generator for this entry. `main.ts` checks that `entry.jpg` is a whole JPEG within the contest limits (at most 1 MiB and 1024x1024 pixels), then copies its bytes unchanged to `entry.png` in the output folder.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
